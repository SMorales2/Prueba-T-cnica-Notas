Portal de Equipo con Tablero de NotasAplicación web full-stack para gestión compartida de notas tipo post-it en lienzo libre, administración de usuarios por roles y visualización de métricas mediante AWS Lambda.  Cuentas de DemostraciónAdministrador: admin@fixlat.com | Clave: admin123  Usuario: user@fixlat.com | Clave: user123  Requisitos Previos y Ejecución LocalDocker y Docker Compose instaldos.  Bash# Levantar todo el entorno local
docker compose up --build
Frontend: http://localhost:3000  Backend API (Laravel): http://localhost:8000  Métricas Lambda (Node.js): http://localhost:3001/metrics  Arquitectura y PersistenciaBase de Datos: SQLite local montada dentro del contenedor backend.  Persistencia: Las coordenadas X/Y y el contenido de los post-it se conservan en la base de datos al reiniciar el entorno.  AWS Lambda Local: Un contenedor independiente en Node.js consulta la API del backend para procesar métricas en tiempo real.
